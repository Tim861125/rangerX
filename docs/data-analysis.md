## D1 對應策略

- `ranger_id` 為主鍵。
- `data_json` 保存完整來源物件並加上 `json_valid` constraint。
- 名稱、敘述、日期、星數、類型、屬性、費用與主要戰鬥數值使用 generated columns。
- 對複合篩選、日期、體力、物攻與魔攻建立索引。
- 關鍵字搜尋可涵蓋 `data_json`，因此技能、能力與才能內容也能被找到。
- 同步前比較現有 JSON，只 upsert 新增／變更資料；不存在於新來源的 ID 透過 `json_each(?)` 單一查詢刪除。
